# Remy

**This repository is archived and no longer updated.**

Remy, the spec-building and coding agent behind [Remy](https://goremy.ai), now lives in the Remy platform's own repository, at `apps/agent/remy`. It is built from the same commit as the rest of the platform, straight into the dev box it runs in, and is no longer published to npm: `@mindstudio-ai/remy` is deprecated, and its existing versions stay installable.

The history here is kept as a record of how the agent got to where it is.
